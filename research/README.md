# ROM-specific cheat research — candidates only

This private research report records potential cheat files for the user's 97 supplied entries; it does not include ROM data. Matches are based on No-Intro metadata SHA-1 for the full file or explicitly header-stripped data, followed by exact metadata name matching to a cheat filename. This is a research lead, NOT proof that an individual code works or that gameplay semantics are correct. Header-stripped matches in particular do not verify identical mapper/header behavior. A title match to a grouped database game name may not by itself distinguish all revisions. Do not copy these candidates into verified_cheats without exact-ROM and feature-specific tests.
